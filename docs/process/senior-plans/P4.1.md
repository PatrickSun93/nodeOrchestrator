## 1. Context

The runtime executes tools but the agent loop is **open at one end** (ADR-028 D4): a tool result never feeds back in-turn, so no "read file → search the symbol → open the reference" within one turn. P4.1 closes the loop (**B1**) + gives it read-only code-intel to chain (**B2**). The 4 brief decision points are architect-ratified: bounded-loop ≤N (small documented N) / 4 code-intel tools + `log_event` / single-lens R0-A / new ADR-033 + amend 028/011.

**Plan-stage R0-A (`reviews/P4.1/R0-A-on-plan.md`, 0R/3Y/10G) verified the spine sound; the architect routed all 3 yellows as in-cycle absorb (these grow the slice):**
- **Y1 (liveness) = α + wall-clock deadline** → ADR-033 D4 now enumerates the dominant term with ADR-028-D5 rigor (`(speaking agents) × provider timeout_s` — **up to 600s** `claude_code_cli` / 60s `openai_compatible` — `× (1+N)`, a **cross-room** head-of-line block on the single writer), and D3 adds an overall **wall-clock deadline** `MAX_TURN_LOOP_WALL_CLOCK_S = 120.0` (the 4th termination condition) → atomic **P4.1-5**.
- **Y2 (dormant-in-production) = β** → bundle a **minimal `cooldown_seconds=0` investigator agent** (`config/agents/investigator.yaml`) so the flagship chain runs **live on landing**, not only in a test agent (ADR-033 D5) → atomic **P4.1-7**.
- **Y3 (context fidelity) = bundle `snapshot_excerpt`** → resolve the P1.4 deferral: a re-dispatched agent sees its **accumulated** investigation, not only the latest result (ADR-033 D2/D6 + the substantive ADR-011 amendment) → atomic **P4.1-6**.

Verified substrate facts that shape the design (R0-A re-verified each vs `origin/main` d878f26): `dispatch_turn` feeds the LLM only `current_event.content` (`agents/dispatch.py:112`) and `build_agent_context` ignores the snapshot (`agents/selection.py:99`) → Y3 wires `snapshot_excerpt`; cooldown suppresses any `cooldown_seconds>0` agent in the sub-second loop (`agents/speaking.py:71`) → Y2 ships a `cooldown=0` agent; `run_turn` evaluates `next_room_state` before dispatch (`rooms/runtime.py:86`) → re-dispatch passes call `dispatch_turn` directly (state machine once/turn); provider timeouts 600s/60s (`providers/claude_code_cli.py:84`, `providers/openai_compatible.py:67`) → the Y1 dominant term; the single writer is `ThreadPoolExecutor(max_workers=1)` (`api/app.py:171`) → the cross-room block.

Read for full rationale: **ADR-033** D1 (shape/N) · D2 (current_event trigger + `snapshot_excerpt` context) · D3 (termination incl. wall-clock deadline) · D4 (enumerated liveness bound + cross-room + cooldown) · D5 (B2 tools + `log_event` + the investigator agent) · D6 (constitution + the ADR-011 amendment).

## 2. Tasks (atomic)

### P4.1-1 — Extract `select_dispatch_agents` from `run_turn` (behavior-preserving)
- **What**: factor `run_turn`'s load-time + dispatch-time agent filter (`rooms/runtime.py:106-115`) into pure `select_dispatch_agents(room, available_agents) -> dict[str, Agent]`; `run_turn` calls it. No behavior change.
- **Where**: `src/orchestrator/rooms/runtime.py`; tests `tests/rooms/`.
- **Why**: ADR-033 D2 — the driver loop reuses the same filtered set per re-dispatch pass (single source of truth).
- **Acceptance**: helper pure (no I/O/LLM); `run_turn` behavior identical (existing `tests/rooms/` green); a direct unit test of the filter (load-time `applies_to.room_types` + dispatch-time `room.state ∈ {["*"], applies_to.room_states}`).
- **Out of scope**: any `next_room_state`/dispatch change.

### P4.1-2 — B2 read-only code-intel tools + bounded traversal + registry
- **What**: in-process `search_text(query, scope=None)`, `search_code(pattern, scope=None)`, `find_references(symbol, scope=None)`, `find_definition(symbol, scope=None)` in `tools/local.py`; register in `build_local_tool_registry`. Shared `os.walk` helper reusing `_check_path` (on `scope`), bounded output (`MAX_RESULT_BYTES`), **new files-scanned cap `MAX_SEARCH_FILES`** + bounded per-file read.
- **Where**: `src/orchestrator/tools/local.py`; tests `tests/tools/test_local.py`.
- **Why**: ADR-033 D5 / ADR-028 D3 amendment; carry-forward #6 (in-process; no `grep`/`rg`/`git grep`/language-server).
- **Acceptance**: each returns `file:line` hits within sandbox; `scope` escape → `TOOL_FAILED`; output capped (`output_truncated_at`); traversal stops at `MAX_SEARCH_FILES`; **no subprocess** (asserted P4.1-8); `find_definition` matches `def/class/<name> =`; results → `LocalToolOutput` (→ `TOOL_RESULT`, no `OBSERVATION`).
- **Out of scope**: AST/language-server precision; `read_file` `range=`; subprocess/network/mutation tools.

### P4.1-3 — `log_event` tool + registry
- **What**: `log_event(content, type)` in `tools/local.py` (register): returns a `LocalToolOutput` recording the note + `type` → lands as `TOOL_RESULT`. No `event_store` handle; no new `EventType`; bounded note (`MAX_RESULT_BYTES`).
- **Where**: `src/orchestrator/tools/local.py`; tests `tests/tools/test_local.py`.
- **Why**: ADR-033 D5 (rev-8 triviality accepted; no per-pass write-cap this cycle — forward-watch named).
- **Acceptance**: content+type recorded in the output + appear as `TOOL_RESULT` through the executor; signature stays `dict → LocalToolOutput`; `core/event.py` `EventType` unchanged.
- **Out of scope**: `MAX_LOCAL_WRITES_PER_PASS` cap; a `NOTE` event type.

### P4.1-4 — B1 driver turn-loop (N + zero-new-`TOOL_CALL` + no-new-result termination)
- **What**: wrap pass 0 (`run_turn` + `execute_pending_tool_calls`) in a bounded re-dispatch loop in `api/app.py::_write_and_turn`: `MAX_TURN_LOOP_PASSES = 4`; filtered agents once via `select_dispatch_agents`; each re-dispatch pass = `dispatch_turn(filtered, room, current_event=<latest result-class event of prior pass>, …)` then `execute_pending_tool_calls(<new window>)`. Terminate on zero-new-`TOOL_CALL` **or** no-new-result **or** N passes (ADR-033 D1/D2/D3 conditions 1-3). Single publish of the accumulated window at the end.
- **Where**: `src/orchestrator/api/app.py` (`_write_and_turn`); tests `tests/integration/`, `tests/api/`.
- **Why**: ADR-033 D1/D2/D3. Executor + `dispatch_turn` reused **unchanged**.
- **Acceptance**: (§1 chain) a `cooldown=0` mock test agent triggered on `tool_result`, mock LLM returns `read_file` then `search_text` then nothing → one `/intent` turn yields both results **in-turn** and terminates; (§2) a zero-new-`TOOL_CALL` pass exits; `dispatch_turn` invoked ≤ `1+N` times (assert count); (§3) `TOOL_FAILED` mid-loop continues bounded; a `COUNTDOWN`/`HARD` call → `TOOL_CALL_PENDING` (no `TOOL_CALL`) → loop terminates, not executed in-loop, no hang; `next_room_state`/`state_transition` evaluated exactly once/turn.
- **Out of scope**: the wall-clock deadline (P4.1-5); `snapshot_excerpt` (P4.1-6); the `_post_confirm` path; any gate-logic change.

### P4.1-5 — Turn-loop wall-clock deadline (Y1 absorption)
- **What**: add the 4th termination condition to the P4.1-4 loop: `MAX_TURN_LOOP_WALL_CLOCK_S = 120.0`; stamp `loop_start = time.monotonic()` before pass 0; at each pass boundary exit if `monotonic() − loop_start ≥` the deadline.
- **Where**: `src/orchestrator/api/app.py` (`_write_and_turn`); tests `tests/integration/`.
- **Why**: ADR-033 D3 (condition 4) / D4 — bound the **absolute** wall-clock single-writer occupancy, not just the `(1+N)` factor (the cross-room head-of-line block).
- **Acceptance**: a test where each pass's mock LLM sleeps past the deadline → the loop exits at the pass boundary (does **not** start a further re-dispatch); assert total wall-clock ≤ deadline + one pass; a docstring/ADR-cite names the cross-room (single-writer) rationale; in-flight pass is not interrupted (deadline is a boundary check).
- **Out of scope**: mid-pass interruption / async cancellation; a separate execution lane.

### P4.1-6 — `snapshot_excerpt` context fidelity (Y3 absorption — the ADR-011 amendment)
- **What**: add `snapshot_excerpt: str | None = None` to `AgentContext` (`agents/schema.py`); populate it in `build_agent_context` from the snapshot (bounded by `MAX_SNAPSHOT_EXCERPT_CHARS`, most-recent slice rendered as `author: content`); feed it into the `dispatch_turn` LLM prompt (system block alongside persona + skill bodies). Reconcile with D2: `current_event` stays the trigger + final user message; `snapshot_excerpt` is the accumulated context.
- **Where**: `src/orchestrator/agents/schema.py`, `agents/selection.py` (`:99`), `agents/dispatch.py` (`:112`); tests `tests/agents/`.
- **Why**: ADR-033 D2/D6 + the substantive ADR-011 amendment — a re-dispatched agent reasons over **all** prior-pass results, not only the latest. Additive: no new `LLMPurpose`/`EventType`; snapshot-reading stays per-pass (no live reads); gate routes every resulting call.
- **Acceptance**: `AgentContext.snapshot_excerpt` is populated + bounded at `MAX_SNAPSHOT_EXCERPT_CHARS`; a re-dispatched agent's `LLMRequest` provably contains prior-pass result content (assert the excerpt reaches the request); existing `tests/agents/` (P1.4 dispatch/selection) stay green; constitution `no_llm_calls_in_agents_module` stays green.
- **Out of scope**: per-agent excerpt templating; structured (non-string) excerpt; autonomy-aware tool context.

### P4.1-7 — Minimal `cooldown_seconds=0` investigator agent + live chain (Y2 absorption; R2-Y1 threshold pin)
- **What**: add `config/agents/investigator.yaml` — `cooldown_seconds: 0`; `speaking_triggers` = `event_type: user_input` (start) + `event_type: tool_result` (chain on each fed-back result); `required_capabilities: [tools]`; read-only investigation persona (`read_file`/`search_text`/`search_code`/`find_references`/`find_definition`/`log_event`); `applies_to.room_types: [bug_fix, code_review, research]`, `room_states: ["*"]` (architect-confirmed as-is — R2-Y1, no narrowing). **Explicit conservative `autonomy_thresholds` (R2-Y1 absorption): `threshold_auto: 8`, `threshold_confirm: 3`, `user_intent_modifier: 0`** — the roster's first always-on `cooldown=0` agent, pinned least-privilege (ADR-033 D5). Auto-loaded via `load_agents` (`api/app.py:176`).
- **Where**: `config/agents/investigator.yaml`; tests `tests/integration/`, `tests/agents/` (loader).
- **Why**: ADR-033 D5 — the loop ships **live** (the existing `operator` at `cooldown_seconds: 10` cannot chain). - **Acceptance**: the agent loads + validates (loader green; `ThresholdConfig` invariant `threshold_auto > threshold_confirm` holds: 8 > 3); a **live** integration test (real agent config, mock LLM/provider) drives the flagship chain through the loop via `investigator` (not a synthetic test agent); a test asserts a mutation tool proposed by the investigator does **not** AUTO-execute (lands COUNTDOWN/HARD); **promotion-impact grep** (Pre-investigation (b)): grep for tests/fixtures that enumerate `config/agents/` count or names (e.g. roster-count assertions) and update them in this atomic.
