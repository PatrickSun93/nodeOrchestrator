# Architect briefs

Architect → senior task briefs. One file per task, named `{task-id}.md`
(e.g. `P1.2-C3.md`). Written by architect; read by senior before any
plan starts. Carries scope, architect-settled design decisions, the
test-coverage-standard application table, predicted push-back points,
and the deliverable contract. Git-tracked so architect intent persists
beyond chat sessions.

If you (senior) start a task and no brief file matches the task ID,
stop and ask the architect — do not assume the brief is "implied".
