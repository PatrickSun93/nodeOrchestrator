### C1 — `MockProvider` concurrent cursor safety
- **Number**: P1.2-R0-1.
- **Where**: `src/orchestrator/llm/providers/mock.py` and `tests/llm/test_mock_provider.py`.
- **Why**: P1.1-R0-1 from close-out audit. Standard: `docs/architecture/test-coverage-standard.md` §2 (concurrency safety). The cursor race becomes load-bearing in P1.4 multi-agent dispatch.
- **What**: add an `asyncio.Lock` field to `MockProvider`; wrap the cursor-advance + `_calls.append` mutation in `async with self._lock:`. Add one constitutional test (prefix `test_constitution_`) that fires 20 concurrent calls via `asyncio.gather` against a single `MockProvider` instance and asserts all 20 distinct response contents are present.
- **Acceptance**: lock present and wrapping the mutation; new test passes; all 16 existing mock tests still pass; mypy/ruff clean.
- **Out of scope**: applying the same pattern to `OpenAICompatibleProvider` or `ClaudeCodeCliProvider` (they don't share mutable state across calls).

### C3 — Harden `claude_code_cli` cleanup paths
