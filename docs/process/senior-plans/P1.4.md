## 1. Context

P1.4 is **the first project task with categorical shape change** —
multi-agent concurrency dispatch. Per the brief, three new decision
functions land in `src/orchestrator/agents/`: `decide_agents_for_room`,
`should_agent_speak`, and the multi-agent turn-dispatch primitive.
All three are code per Principle 3.1; LLM calls fire only for agent
response content generation.

Two ADRs land alongside the plan: ADR-010 inscribes the
`should_agent_speak` contract (trigger types, cooldown semantics,
SpeechDecision shape, snapshot invariant, load-time validation);
ADR-011 inscribes the dispatch model (sequential for P1.4 with
additive concurrent path, per-turn snapshot semantics, priority +
alphabetical conflict resolution, separate `build_agent_context`
function, layering rules). **Summon decision is deferred to P1.5**
(senior push-back #1 below). ADR-012 is not drafted.

Three constraints external to the brief:

- **W-002 sequencing.** The brief mandates W-002 lands before P1.4
  Accept-gate work because P1.4 hits the `awaiting_architect_accept`
  state twice (once per ADR) and the override workaround is too
  noisy at that frequency. Plan-writing is doc-only; Accept-gate
  work is what triggers the dependency. The plan can be drafted
  and pushed to `claude/P1.4-plan` now; architect Accepts on ADRs
  wait for W-002 to land first.
- **Cross-family R0-B mandatory.** Brief is unambiguous: P1.4 is
  the first task crossing the threshold from "shape-stable" to
  "shape-change", and cross-family review is the project's
  highest-quality review surface. Dispatch after senior plan +
  ADRs draft, before architect Accept on either ADR.
- **Distance test discipline.** Two ADR Accepts each require full
  substrate distance per `docs/process/distance-test.md`. Plan-
  stage same-day OK; impl after both ADRs Accepted with proper
  pauses.

  from __future__ import annotations
  from typing import Annotated, Literal
  from pydantic import BaseModel, ConfigDict, Field, field_validator
  from orchestrator.core.event import EventType
  from orchestrator.core.room import RoomType
  from orchestrator.llm.types import AgentLLMConfig

  # --- speaking triggers (ADR-010 Decision 1) ---

  class RegexTrigger(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      type: Literal["regex"] = "regex"
      pattern: str = Field(min_length=1)

  class EventTypeTrigger(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      type: Literal["event_type"] = "event_type"
      event_type: EventType

  class StateChangeTrigger(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      type: Literal["state_change"] = "state_change"
      target_state: str = Field(min_length=1)

  SpeakingTrigger = Annotated[
      RegexTrigger | EventTypeTrigger | StateChangeTrigger,
      Field(discriminator="type"),
  ]

      id: str = Field(min_length=1)
      role: str = Field(min_length=1)
      persona: str = Field(min_length=1)
      dissent_dimensions: list[str] = Field(default_factory=list)

  # --- speech decision (ADR-010 D3) ---

  class SpeechDecision(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      agent_id: str
      speak: bool
      reason: Literal[
          "trigger_matched",
          "no_trigger_matched",
          "cooldown_active",
          "no_triggers_configured",
      ]
      matched_trigger_index: int | None = None
      cooldown_remaining_s: float | None = None

  # --- agent selection (ADR-011 dispatch consumer) ---

  class AgentMatchRecord(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      agent_id: str
      loaded: bool
      reason: Literal["room_type_matched", "room_type_mismatch"]

  class AgentSelectionTrace(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      considered: list[AgentMatchRecord]
      loaded_count: int = Field(ge=0)

  class AgentSelection(BaseModel):
      model_config = ConfigDict(frozen=True, extra="forbid")
      loaded: list[Agent]   # ordered by priority asc, then id asc
      trace: AgentSelectionTrace

  # --- agent context (ADR-011 D4) ---

  class AgentContext(BaseModel):
