# Demo Research Skill

A demonstration skill shipped by the demo plugin bundle (ADR-029 D7).
Provides a simple research scaffolding for use in free-chat rooms.

When exploring a topic:
1. State the question clearly.
2. Break it into two independent sub-questions.
3. Address each sub-question with a brief observation.
4. Synthesize into a one-sentence conclusion.
