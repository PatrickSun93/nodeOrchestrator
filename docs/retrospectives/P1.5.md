## 2. Meta-lesson — validation by absence; the W-002-2 fix proves itself by NOT activating

**The single most important observation from P1.5 is the inverted proof.**

W-002-2 fixed the `record_override` cycle-counter bug. The fix narrowed the increment condition from "any override to AWAITING_JUNIOR_IMPL" to "specifically awaiting_architect_decision → awaiting_junior_impl (real rework)." P1.3 and W-002 had the bug; their final state files show `cycle: 2` despite running only one cycle's worth of work each (durable bug evidence in `.workflow/P1.3.yaml` + `.workflow/W-002.yaml`).

P1.5 had the **first R1 (rework) event in project history**:
- Plan-vs-impl review found `test_state_transition_event_before_utterance` failing under full-suite (passing isolated).
- Diagnosis (independently re-derived in R0-A G3): `get_room_events ORDER BY (timestamp, id)` where `id` is a random UUID; ms-tied timestamps + random secondary sort = non-deterministic ordering.
- Junior fixed via `307a8fa`: `ORDER BY (timestamp, rowid)`. SQLite `rowid` is the implicit B-tree key + insertion-order monotonic.
- Plan-vs-impl verdict bumped blocking → clean (RC-10 protocol, 6th use).

**Crucially**, this R1 was a **fix-on-same-branch**, not a `workflow override` invocation. The state machine's `awaiting_senior_plan_vs_impl` state didn't move; junior pushed a fix commit; senior re-reviewed and bumped verdict. No `awaiting_architect_decision → awaiting_junior_impl` transition fired.

**Therefore the W-002-2 fix's correctness was tested by the cycle counter STAYING at 1.** If the fix were wrong (e.g., if it still incremented on any override touching junior_impl), the R1 event wouldn't have triggered cycle increment anyway (no override invoked). The bug class W-002-2 closed (incorrect-cycle-increment-on-non-rework-override) doesn't activate without an override.

**This is validation-by-absence**: the fix is correct because the bug doesn't manifest. Different from P1.4's dual-lens R0-B (validation-by-finding); different from P1.3's RC-11 surfacing (validation-by-predicted-gap). P1.5 demonstrates that the harness can reach the **mature steady state** where fixes work and their working = silence. The cycle counter staying at 1 is the most expensive cheap signal in the project.

Three consecutive zero-override cycles (W-002.5 → P1.4 → P1.5) follow. The RC-11 cluster (a + b + c + multi-ADR sibling) is now structurally AND operationally closed.
