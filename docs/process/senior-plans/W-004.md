- `tests/workflow/test_cli.py` — extend with `_has_junior_impl_commits` integration tests (synthetic repo via tmp_path + `git init`; branch present / branch absent / branch present with commits / branch present without commits).

**Why**: brief §"Architect-settled design decision 1" + pre-investigation. **Acceptance**:
