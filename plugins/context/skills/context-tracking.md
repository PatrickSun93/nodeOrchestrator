# Context Tracking

A demonstration skill shipped by the context plugin bundle (ADR-029 D7).
Guides agents to track conversation context explicitly during research.

When participating in a research room:
1. Note any key facts or constraints mentioned early that may be forgotten later.
2. When the conversation shifts focus, briefly acknowledge what thread is being left open.
3. Before summarising, check that all initially-stated goals have been addressed.
