## 1. Context

P2.5 is the P2 **acceptance milestone** — room re-entry / 离开-回来追平 ("AI 记得我"): when a user leaves a room, generate a catch-up artifact; when they return, **catch them up** by reading the memory containers (P2.1–2.4) and assembling a "here's what you missed / here's what I remember" digest. It is the **first consumer** of the entire read-side surface (`lookup_verified_knowledge` + `Entity`/preferences + `ProjectArchive` + `snapshot`) — every reader's first runtime exercise. It demos on **rule-b-promoted VK** (no producers needed — those are P2.6).

The constitutional crux (the recurring rule, a **fourth time**): **code decides *what* and *in what order*; the LLM only *phrases*.** Selection, ranking, ordering, and "what's new since you left" are pure code (deterministic readers + a code diff against a persisted leave-marker); the LLM does content-gen prose render over the already-assembled fact-set only — never selection/judgment (Principle 11; Principle 5 keeps the LLM out of `memory/`, and the consumer's only LLM call is a content-gen render). ADR-021 carries the full design; this plan is its atomic execution. All substrate verified against `origin/main` (cites §5/§7).

**Architect-ruled (a/b/c) — written here, not re-surfaced:** (a) **one slice** (re-entry assembly + leave-time generation, one ADR-021); (b) **dual-lens R0-B dispatched** (`requires_cross_family_review: true` + external prompt); (c) **MVP includes the LLM prose-render** (the felt "AI 记得我"). §5 records these + the four senior design forks I pinned.

### P2.5-3 — Leave-time generation: marker upsert + tag-derivation + ProjectArchive composition

- **What**: `reentry/leave.py` — the leave-time half (decision a).
- **Where**: `src/orchestrator/reentry/leave.py`:

  - leave-time archive composition: compose `produce_decision_log(events, room)` (ADR-015) + a leave-time `produce_snapshot` + the content-gen summary fields (`one_line_summary`/`spinoff_questions` — produced via the render path / passed in), then `record_project_archive(...)` (ADR-020 D3). `reentry/` composes the derivation; `memory/` persists.
- **Why**: ADR-021 D5/D6/D8.
- **Acceptance**:
  1. `record_leave_marker` upserts (second leave for same `(room,user)` → one row, latest ts); discriminating (asserts one row + latest value).
  2. `derive_query_tags` deterministic; empty-room → `[]`.
  3. Leave composes the archive from the existing derivations (does **not** re-derive on read; `reentry/` does the composing, `memory/` persists); the semantic fields are content-gen (not generated inside `memory/`).
- **Out of scope**: the re-entry assembly (P2.5-4).

### P2.5-4 — `assemble_reentry` — the deterministic catch-up assembly (pure code, NO LLM)

- **What**: `reentry/digest.py` — `assemble_reentry(room_id, user_id, *, conn, events, room, now) -> ReentryDigest`.
- **Where**: `src/orchestrator/reentry/digest.py`.
- **Why**: ADR-021 D3 (the milestone core).
- **Acceptance**:
  1. Composes, all code-driven: VK via `lookup_verified_knowledge(derive_query_tags(...), scope, conn=conn)` **only if tags non-empty** (else `recalled_knowledge=[]` — does NOT pass `[]` to lookup, ADR-016 D6 raises); `list_entities` + `list_preferences(user_id=...)`; `get_project_archive(room_id)` (`None` first visit); `produce_snapshot` + the **code diff** vs `last_seen_ts` (facts with timestamp/`last_validated` > marker → `new_since_leave`).
  2. **Pure code — no LLM** (asserted by the AST guard, P2.5-5): `assemble_reentry` + `derive_query_tags` + the diff reference no `LLMRequest`/`llm_router`.
  3. **Deterministic**: same inputs → same digest; ordering stable (readers' own order + timestamp-sorted diff). Discriminating test (assert the **exact** surfaced set by stable labels — RC-25 anti-pattern; not count-only).
  4. Returns a frozen `ReentryDigest`.
- **Out of scope**: the prose render (P2.5-5).

### P2.5-5 — `render_reentry_prose` (content-gen LLM) + the constitutional guards

- **What**: `reentry/render.py` + the top-level `reenter(...)` + two constitutional guards.
- **Where**:
  - `src/orchestrator/reentry/render.py` — `render_reentry_prose(digest, *, llm_router) -> str`: build `LLMRequest(purpose=LLMPurpose.REENTRY_DIGEST_RENDER, caller_agent_id=None, system=<render-only, add-no-facts>, messages=[serialized digest])` → `llm_router.call(...)` (mirror `agents/dispatch.py`). Content-gen; phrases the frozen digest, selects nothing.
  - `reentry/__init__.py` (or digest.py) — `reenter(room_id, user_id, *, conn, llm_router, events, room, now) -> ReentryResult` composing `assemble_reentry` then `render_reentry_prose`.
  - `tests/.../test_constitution*.py` (new or extend) — two **AST guards** (real AST, not substring — RC-24): (i) **`memory/` and `core/` do not import `reentry/`** (mirror the existing `core`-no-import guards); (ii) **the assembly path is LLM-free** — `digest.py`'s `assemble_reentry`/`derive_query_tags`/diff reference no `LLMRequest`/`llm_router`/`.call(` (the LLM is confined to `render.py`).
- **Why**: ADR-021 D1/D4/D6 (the code/LLM boundary, structurally enforced).
- **Acceptance**:
  1. `render_reentry_prose` uses `LLMPurpose.REENTRY_DIGEST_RENDER` (content-gen — grep `LLMPurpose` confirms; **Q1**: the render genuinely needs an LLM — phrasing facts into natural language is not code — while selection is code).
  2. The render is exercised (a `MockProvider` keyed on `(REENTRY_DIGEST_RENDER, None)`); its **exact wording is not asserted** (LLM output) — only that it is called over the assembled digest and returns prose.
  3. **Guard (i)**: `memory/`/`core/` importing `reentry/` fails the import guard.
  4. **Guard (ii)**: an LLM reference in `assemble_reentry`/selection fails the LLM-free-selection guard (discriminating — a mis-placed `llm_router` would trip it).
- **Out of scope**: real provider wiring (MockProvider in tests).

**Senior design forks (pinned in ADR-021; verified against `origin/main`):**
- **Placement → `orchestrator/reentry/`** (D1) — outside `memory/` (no-LLM rule); imports `memory/`+`derived/`+`llm/`; `memory/`/`core/` MUST NOT import it (guard).
- **Leave/return marker → a persisted mutable `reentry_marker(room_id,user_id,last_seen_ts)` table** (D5) — snapshot is *derived* (ADR-014; only `summary_snapshot` events persist it), so the "what's new since I left" diff needs a persisted last-seen pointer. Consumer-owned (not `memory/` — it's consumer infrastructure, not a domain fact). An event-type marker was considered + rejected (core-vocab overkill for consumer state).
- **Tag-derivation → `derive_query_tags(room_id, conn)` = code union of the room's hypotheses' canonical `topic_tags`** (D6) — because `lookup_verified_knowledge` requires non-empty tags and Principle 11 forbids an LLM guessing relevance. Empty → skip the VK lookup (never pass `[]`).
- **Return shape → `ReentryDigest` frozen + `extra="forbid"`** (D7) — the code-selected fact-set; the prose is a separate render output (kept out of the deterministic model).

## 7. Predicted self-discoveries (verified against `origin/main`)

- **`lookup_verified_knowledge` requires non-empty `topic_tags`** (lookup.py:33 raises on empty) → the catch-up code-derives tags (D6); passing `[]` raises — a Principle-11 boundary + a cleanup case.
- **`snapshot` is derived, not persisted** (produce_snapshot pure; state only in `summary_snapshot` events) → the "what's new" diff needs a persisted leave-marker (D5), not a stored snapshot.
- **First code to import `memory/` + `derived/` + `llm/` together** → placement outside `memory/` + the dependency-direction guard (D1).
- **All `LLMPurpose` values are content-gen** (purposes.py — no routing/judgment purpose exists); adding `REENTRY_DIGEST_RENDER` is ADR-gated (purposes.py "adding a purpose requires an ADR") and content-gen — the render is the only LLM surface, confined to `render.py` (the LLM-free-selection guard enforces it).
- **`ProjectArchive` has no producer yet** → P2.5 ships the minimal leave-time generator (decision a) composing the existing derivations; the e2e also test-injects to exercise the empty/seeded paths.
- **The render is non-deterministic** → the `ReentryDigest` (code) is the deterministic tested core; the prose is exercised via `MockProvider`, wording not asserted.
