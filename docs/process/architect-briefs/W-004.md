## Architect-settled design decisions

### 1. RC-19 fix is task-scoped junior-impl detection (lean: branch-presence)

The decision **"has junior dispatched and pushed?"** is the load-bearing semantic. Current `_has_commit_since` answers a weaker question ("has ANY commit happened?"). The architect-partner lean is **branch-presence filter** (`claude/{task_id}-impl` exists + has commits since `time`). Rationale:

- Junior commits land on a task-scoped branch by convention (`claude/<task_id>-impl` per CLAUDE.md); the convention is already universal.
- Branch-existence is a binary signal independent of commit subject formatting; immune to merge-commit naming variations.
- Subject-prefix filter (alternative) requires a stable subject convention; works in practice but has bus-factor (a junior who forgets the convention silently invalidates the filter; CI doesn't enforce subjects).
- File-touch filter (alternative) requires per-task file-allowlist OR per-cycle inference; non-trivial.

Senior **may push back on the branch-presence vs subject-prefix choice** at plan time (see push-back #1).

### 2. 3 codification rules land as a single doc commit

Codifications (a)-(c) are tightly related — all three close gaps in the "senior pre-investigates / catches at plan stage instead of impl stage" discipline arc. Bundling as one commit makes the trio readable as a coherent discipline-rule upgrade rather than three separate fragments.

Naming convention: commit subject `W-004-2: senior-planner.md + CLAUDE.md — claims-without-cites + promotion-impact-grep + architect-deferral-literal-reading addenda`. Atomic-task discipline holds (one subject), with the three rules enumerated.

### 3. Joint retro shape: single file, dual-cycle scope

`docs/retrospectives/W-003+P1.5.5.md` — first explicit joint-retro naming. Rationale: both cycles surfaced the same pattern-recurrence threshold (3+ instances of "pre-investigation gap"); the codifications (W-004-2) cover both cycles' findings; the RC-18+RC-19 incident chain bridges the cycles. Single file preserves the bridging narrative. ~300-500 lines (similar density to P1.5.md retro).

W-004 is **pure cleanup**, not new architecture.
