## 1. Context

P1.4 closed the multi-agent dispatch contract end-to-end (cycle 1
clean; first P1.x task to do so). P1.5 introduces the **third
code-driven decision-function module** in the project (`autonomy/gate`
→ `skills/decide_skills_for_context` + `agents/should_agent_speak`
→ `rooms/next_room_state`). The pattern stays consistent per
Principle 3.1: pure function, no LLM, event-stream-driven.

Scope is deliberately cut to "Research room as architectural
exemplar." Operator agent + autonomy-aware tool dispatch defer
to P1.5.5 (biggest deferred P1.4 item). divergence_mapper + logger
yamls defer to P1.5.5 unless trivial-to-include. The 4 non-Research
RoomTypes get scaffold-only state machines (`{setup, closed}`); the
content polish lands as P2 work. **Audit item #6 (P1.4-P1.5
boundary drift)** explicitly drives this scope cut.

ADR-012 (drafted alongside this plan) inscribes seven decisions:
per-RoomType state machines (code-driven, event-triggered);
`next_room_state` pure-function signature; per-RoomType state
Literals; `agent.applies_to` with `["*"]` sentinel; two-layer
filtering (`room_types` load-time + `room_states` dispatch-time);
`RoomRuntime` orchestrator (separate from `dispatch_turn`);
`StateTransitionMeta` extension with `prior_state`; four new
constitutional tests for the layering edges.

  - Per-RoomType Literals declared per ADR-012 D2:
    - `ResearchRoomState = Literal["setup", "exploration", "divergence", "convergence", "snapshot_pending", "closed"]` (6 states, fully impl).
    - `BugFixRoomState`, `CodeReviewRoomState`, `IdeaValidationRoomState`, `FreeChatRoomState` each = `Literal["setup", "closed"]` (2 states, scaffold).
  - `RoomStateTransition(BaseModel)`: frozen + extra-forbid; fields `prior_state: str`, `new_state: str`, `triggering_event_type: EventType`, `rule_matched: str` (a short rule identifier — e.g., `"hypothesis_density_triggers_divergence"`).
  - `next_room_state` signature exactly:
    ```python
    def next_room_state(
        room: Room,
        event_stream_snapshot: list[Event],
        *,
        current_event: Event,
    ) -> RoomStateTransition | None: ...
    ```
  - Per-RoomType dispatch: `next_room_state` checks `room.type` and routes to per-RoomType transition logic. Each per-RoomType function returns `RoomStateTransition | None`.
  - Research transition rules (senior call — defensible against architect-partner lean):
    - `setup → exploration`: first `utterance` event by any agent.
    - `exploration → divergence`: when ≥2 distinct `hypothesis` events exist in snapshot AND current_event is also `hypothesis`. (Density-triggered.)
    - `divergence → convergence`: when current_event is `user_input` with content matching `r"(?i)\b(decide|choose|pick|finalize)\b"`. (User-explicit-decide intent.)
    - `convergence → snapshot_pending`: when a `decision` event is appended.
    - `snapshot_pending → closed`: when a `summary_snapshot` event is appended.
    - Cycles allowed: `exploration → divergence → exploration` if user re-prompts for more hypotheses (senior judgment per self-discovery #3; no cycle-count enforcement in P1.5; surface cycle count to caller via trace).
  - Scaffold RoomTypes: only `setup → closed` transitions; trigger is a `state_transition` event with `new_state: "closed"` (architect-driven; no automatic close).
  - Recency window (self-discovery #2): `next_room_state` reads the last N events of the snapshot, where N defaults to 50 (configurable per RoomType; senior pins `N=50` for Research). Bounded read; not whole-stream. Documented in docstring.
  - `RoomStateError` payload includes `room_id`, `current_state`, `attempted_transition_rule`, raised on internal contract violations (e.g., a transition rule fires but the resulting state isn't in the RoomType's Literal — defensive).
  - Tests (≥10): each Research transition (5 happy paths); no-transition cases (most events don't transition); cycle case (exploration → divergence → exploration); scaffold RoomType passthrough; recency window respected (event older than N is ignored); RoomStateError raised on invalid transition.
  - All tests green; mypy strict; ruff clean.

### P1.5-7 — `RoomRuntime` orchestrator + integration test

- **What**: implement `RoomRuntime` (function-based per ADR-012 D5 lean): a function `run_turn(room, current_event, *, available_agents, available_skills, event_store, llm_router, regex_registry) -> TurnResult` that orchestrates per-turn: take snapshot → `next_room_state` → append `state_transition` if transition → `decide_agents_for_room(room.type, room.state, available_agents=...)` filtered by load-time → dispatch-time filter on `room_states` → `dispatch_turn(filtered_agents, ...)`. Returns `TurnResult` from `dispatch_turn`.
- **Where**:
  - New: `src/orchestrator/rooms/runtime.py`.
  - New: `tests/rooms/test_runtime.py`.
- **Why**: ADR-012 D5 (separate orchestrator); brief Architect-settled decision 2 (integration site post-loop); §1 cross-module integration.
- **Acceptance**:
  - `run_turn` signature exactly:
    ```python
    def run_turn(
        room: Room,
        current_event: Event,
        *,
        available_agents: dict[str, Agent],
        available_skills: dict[str, Skill],
        event_store: EventStore,
        llm_router: LLMRouter,
        regex_registry: dict[tuple[str, int], re.Pattern[str]],
    ) -> TurnResult: ...
    ```
  - Body (sync per ADR-011 D1):
    1. `snapshot = event_store.get_events(room.id)`
    2. `transition = next_room_state(room, snapshot, current_event=current_event)`
    3. If `transition is not None`: append `Event(type=STATE_TRANSITION, metadata=StateTransitionMeta(prior_state=transition.prior_state, new_state=transition.new_state), ...)`; **note: room.state is NOT mutated here** — the next turn's snapshot will reflect the new state via the appended event; for THIS turn, dispatch uses the state pre-transition. (Senior judgement: state changes apply to the NEXT turn, not the same turn the trigger fired. Cleaner causality; matches per-turn snapshot semantics from ADR-011 D2.)
    4. `selection = decide_agents_for_room(room.type, room.state, available_agents=available_agents)`
    5. Filter `selection.loaded` by `room_states`: keep agent iff `room.state in agent.applies_to.room_states` OR `agent.applies_to.room_states == ["*"]`.
    6. `result = dispatch_turn(filtered, room, current_event, event_store=event_store, llm_router=llm_router, available_skills=available_skills, regex_registry=regex_registry)`
    7. Return `result`.
  - Tests (≥7 including §1 integration): full pipeline (Research room + 2 agents + hypothesis events → transitions through 2 states → utterances appended); state transition appended before dispatch (verify event ordering in store); state changes apply to NEXT turn, not same turn (verify state at end of turn N equals state at start of turn N+1 only after the N+1 snapshot reads the transition event); empty agent set after dispatch-time filter → empty `TurnResult.utterances`; no transition → no `state_transition` event appended; `RoomStateError` propagates; **§1 source ≠ sink integration test**: Research room loaded with skeptic + prober → state advances `setup → exploration` after first utterance; assert subsequent `decide_agents_for_room` is called with the NEW state (not the prior); `dispatch_turn` returns `TurnResult` with utterances referencing the actual loaded agents (source) ≠ a sentinel default (sink).
  - All tests green.
